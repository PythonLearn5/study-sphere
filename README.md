### 关于

**Study Sphere** 是一个智能且多功能的学习平台，旨在提升您的学习效率。凭借现代化的界面和强大的 AI 支持，它通过四大核心功能提供沉浸式和个性化的教育体验：

- 📝 **笔记**：轻松创建、管理和整理您的学习笔记。
- ❓ **测验**：通过学科特定的测验挑战自己，并跟踪您的学习进度。
- 🃏 **闪卡生成器**：利用 AI 从您的学习材料中生成闪卡，实现高效记忆。
- 🤖 **学习伙伴（AI 导师）**：从您的 AI 学习助手中获取即时帮助、讲解和指导。

使用 **Study Sphere** 开启您的智慧学习之旅 —— 在这里，学习与创新相遇。

<summary>📦 <strong>安装设置</strong></summary>

要在本地启动并运行 **Study Sphere**，请按以下步骤操作：

1. **克隆仓库：**
   ```sh
   git clone https://github.com/k0msenapati/study-sphere.git
   ```

2. **安装依赖：**

   ```sh
   bun install
   ```

3. **添加环境变量：**

   在根目录中创建 `.env.local` 文件并添加您的 API 密钥：

   ```sh
   LLM_API_KEY='YOUR VERCEL AI GATEWAY KEY HERE'      # 推荐 vck_ 开头
   OPENAI_API_KEY='YOUR VERCEL AI GATEWAY KEY HERE'   # 同上，兼容别名
   NEXT_PUBLIC_RECAPTCHA_SITE_KEY='your_recaptcha_site_key_here'
   RECAPTCHA_SECRET_KEY='your_recaptcha_secret_key_here'
   ```

4. **运行开发服务器：**

   ```sh
   bun run dev
   ```

</details>
